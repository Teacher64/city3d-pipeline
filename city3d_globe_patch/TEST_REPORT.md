# Проверки комплекта — 19.10.2026

Проверки выполнены в изолированной среде Python 3.12.14. На сервере пользователя с Python 3.14.4 комплект ещё не запускался. Установщик повторяет встроенные проверки в окружении, из которого его запускает оператор.

## Автоматические проверки

- Чтение реальных синтетических LAS в QThread, автоматические флажки, просмотр двух файлов.
- Полная проверка и формирование рабочего облака из двух LAS (10 точек), сохранение классов, активация без вызова OpenGL.
- Удаление из проекта, сброс активного состояния, сохранность исходников, сохранение исключений после перезапуска и повторное добавление.
- Совмещение одинакового местоположения из разных UTM-зон; отсутствие CRS одного файла не блокирует остальные.
- Ограниченная выборка: до 16 000 из 100 000 точек LAS.
- Журнал ошибок рабочего потока, компактные кнопки.
- Чтение MBTiles с инверсией TMS-строк; отсутствие сетевого обращения при промахе автономного кэша.
- Порядок координат WMS 1.3.0, проверка реестра сервисов.
- Предварительная проверка установщика, установка, повторная установка, отказ отката при изменённом пользователем исходнике и точный откат с удалением установленных ресурсов.

## Глобус в браузере

Chromium 153, программный WebGL, внешние запросы заблокированы. Локальная текстура загружена, размещены два облака, ошибок страницы нет, внешних запросов нет. Проверено переключение на провайдер MBTiles. Это не испытание производительности пользовательского GPU.

## Поставщики карт

Проверены логика запросов Google, Bing и Яндекс с подставными ответами API, повторное использование Google-сессии, quadkey Bing и Web Mercator Яндекс. Реальные ключи и платные запросы не использовались. Для NASA GIBS сверены слой и матрица по GetCapabilities. ЕЭКО, Роскадастр и НСПД требуют настройки фактически предоставленного адреса сервиса и слоя; готовое подключение к ним не подтверждено.

## Ограничения проверки

Qt проверялся offscreen; контейнер Open3D и GL-виджет заменены тестовыми объектами, обогащение через БД отключено. Не проверены реальная PostgreSQL, пользовательский GPU, большие LAZ на диске пользователя и весь конвейер обучения/экспорта. Быстрый обзор не выполняет нормализацию облаков для совместного обучения. Высоты на глобусе условные: точки размещаются на эллипсоиде для географического обзора.

`city3d_globe_fix_source.py` — читаемая копия устанавливаемого модуля для анализа. Вручную копировать или запускать её не нужно: используйте `apply_globe_patch.py`, который содержит тот же код и встроенные тесты.
