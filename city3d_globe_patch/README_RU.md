# City3D: локальный глобус и быстрое добавление LAS — 19.10.2026

Комплект для присланного `city3d_pipeline_v5(5).py`: патчи 01–03 и исправление компоновки уже стоят, а `fix_city3d_las_loading.py` ещё НЕ установлен. Этот комплект включает его функции. Применять оба исправления последовательно не нужно.

## Установка

Закройте City3D. Распакуйте весь архив в `/mnt/data_sda1/PR_3D_SPB/city3d-pipeline/`. Получится каталог `city3d_globe_patch` с установщиком и ресурсами. Не переносите один установщик отдельно от ресурсов.

```bash
source /home/michel/city3d_env/bin/activate
cd /mnt/data_sda1/PR_3D_SPB/city3d-pipeline/city3d_globe_patch
python apply_globe_patch.py
python apply_globe_patch.py --apply
python ../city3d_pipeline_v5.py
```

Первый запуск проверяет версии, целостность ресурсов и выполняет Qt/LAS-тесты на временных файлах. Рабочий код не меняется. Второй повторяет проверки, сохраняет резервную копию в `/mnt/data_sda1/city3d-backups/`, устанавливает модуль и локальные ресурсы, затем подключает модуль в основной программе. Окружение Python и исходные LAS не меняются. Загрузка зависимостей из интернета при установке не требуется.

Отчёт: `city3d_globe_verification.json` рядом с основным скриптом. При несовпадении исходника или модулей установка останавливается — проверки отключать не надо.

Откат с закрытой программой:

```bash
python apply_globe_patch.py --restore "путь_к_резервной_копии_из_сообщения_установщика"
```

После изменений установленных файлов автоматический откат останавливается, чтобы не затереть последующие правки.

## Работа

1. Добавьте LAS/LAZ или папку. Сначала читаются заголовки, без полного подсчёта классов и SHA256. В таблице это явно отмечено. Новые файлы включаются флажками.
2. Предпросмотр читает до 32 небольших блоков LAS (для LAZ до 8). Обычно не более 16 000 точек на файл, общий бюджет выборки ограничен. Выборка по блокам не гарантирует обнаружение всех мелких объектов.
3. Нажмите «Глобус Земли ↗». Откроется локальная страница в обычном браузере. Сам City3D должен оставаться запущенным: он обслуживает страницу на случайном порту `127.0.0.1` и передаёт выборку координат локально.
4. CesiumJS, текстура NASA Blue Marble и необходимые ресурсы входят в архив. Для запуска глобуса интернет НЕ нужен. Внешние запросы начинаются только после выбора онлайн-подложки. Браузеру нужен WebGL; в Qt остаётся CPU-обзор в плане.
5. Каждое облако преобразуется из своей горизонтальной CRS в WGS84. Разные UTM/МСК-зоны могут отображаться вместе. Без CRS, при конфликте CRS или недоступных сетках преобразования файл остаётся в списке с причиной отказа; прочие файлы продолжают отображаться.
6. Точки глобуса показаны на эллипсоиде. Исходные Z не объявляются эллипсоидальными высотами и не изменяются. Это географический обзор, не точная 3D-модель рельефа. Охват заголовка используется только для навигации, не как рабочая граница.
7. «Перейти к LAS» приближает отдельное облако. «Все облака» показывает общий район. Флажки браузера управляют только видимостью; флажки таблицы Qt — составом обработки.
8. Выделите строки в таблице и нажмите «Убрать из проекта». Исходники и архив результатов остаются на диске. Если удалён источник активного района, активное состояние сбрасывается; оставшиеся файлы нужно применить заново.

«Подготовить рабочий район» и «Записать в БД» сначала выполняют полную проверку ещё не проверенных LAS. Полная проверка, построение границ и загрузка рабочего облака могут быть длительными. Ускорение относится к добавлению и просмотру, а не ко всем этапам обработки.

**Объединение для обучения по-прежнему требует согласованной общей CRS, совместимых LAS-форматов и системы высот. Просмотр на глобусе не заменяет нормализацию рабочих данных.** Нельзя лечить разные зоны назначением всем файлам одинакового EPSG без преобразования координат.

## Локальные карты и геосервисы

- «NASA Blue Marble»: грубая спутниковая мозаика из комплекта, всегда локально.
- «OSM: интернет + кэш»: загружаются только тайлы текущего просмотра; постоянный SQLite-кэш сохраняется в `WORKSPACE/cache/osm/osm_cache.sqlite3`. HTTP-сроки кэширования учитываются, для просроченных тайлов используются условные запросы. Массового скачивания стран со стандартного OSM-сервера нет.
- «OSM: только кэш»: сеть не используется; отсутствующие тайлы остаются прозрачными.
- «База OSM (MBTiles)…»: подключение готовой растровой SQLite/MBTiles базы страны или мира, PNG/JPEG/WebP, Web Mercator, строки тайлов TMS. Это может быть и другая законно полученная картографическая подложка. Векторные MVT/PBF MBTiles и `.osm.pbf` данным reader не отображаются.
- «Геосервисы…»: редактор JSON-реестра. Поддержаны XYZ (включая `{-y}`), WMS 1.1.1/1.3.0 с EPSG:3857, EPSG:4326 или CRS:84; WMTS с совместимой WebMercator XYZ-сеткой и настраиваемыми matrix IDs. Произвольные региональные TileMatrixSet этим патчем не нормализуются.
- `cache_allowed` включает постоянный кэш конкретного общего геосервиса, если это разрешено поставщиком. Для Google/Bing/Яндекс локальное архивирование отключено. Изменения реестра появляются в глобусе после обновления страницы.

Конфигурация: `WORKSPACE/city3d_services.json`; выбранная MBTiles: `WORKSPACE/city3d_globe_settings.json`. Здесь WORKSPACE — рабочий каталог программы, обычно `/mnt/data_sda1/PR_3D_SPB/workspace`.

## Состояние поставщиков

| Поставщик | Реализация и условия |
|---|---|
| NASA Blue Marble | Полностью локальная текстура включена. |
| NASA GIBS | WMTS-профиль; слой BlueMarble_ShadedRelief_Bathymetry и матрица GoogleMapsCompatible_Level8 сверены с GetCapabilities. |
| OSM | Онлайн с постоянным кэшем, чтение кэша и растровых MBTiles. База всей страны/мира в архив не включена. |
| Esri World Imagery | XYZ-профиль публичного MapServer; доступность на машине оператора нужно проверить. Архивирование по умолчанию выключено. |
| Google Maps | Официальный 2D Map Tiles API: создание и повторное использование сессии, получение viewport attribution. Нужен ключ; профиль выключен до настройки. Реальные платные запросы не проверялись. |
| Bing Maps | Официальный Imagery Metadata API, шаблон тайлов и quadkey. Нужен действующий ключ/доступ Enterprise; профиль выключен. Basic прекращён, проверьте доступ своей учётной записи. |
| Яндекс | Официальный Tiles API, схема, `projection=web_mercator`; локальный официальный логотип. Нужен ключ Tiles API; профиль выключен. Спутник/гибрид этим API не предоставляются. |
| ЕЭКО / Росреестр | Настраиваемый WMS-профиль с примером адреса из официальной инструкции. Доступность этого адреса не подтверждена, имя слоя не выдумано. Нужны актуальный endpoint, layers и предоставленный оператору доступ. |
| Роскадастр, НСПД России | Записи реестра для настройки предоставленных WMS/WMTS/XYZ. Адреса порталов НЕ считаются рабочими WMS. Автоматическое извлечение закрытых API и вход в аккаунты не реализованы. |

Для Google/Bing/Яндекс укажите ключ в окружении процесса City3D (`CITY3D_GOOGLE_KEY`, `CITY3D_BING_KEY`, `CITY3D_YANDEX_KEY`) и поставьте `enabled: true` у нужного профиля. Ключи не записываются в реестр, страницу и отчёты. Для иных сервисов поддержан `bearer_env` — имя переменной с Bearer-токеном. API может тарифицироваться поставщиком.

Не пересылайте ключи в чат. Реальная доступность зависит от вашей подписки, ограничений ключа и сети. Профиль в реестре не равен проверенному действующему подключению.

## Проверки и ограничения

Встроенные тесты: чтение настоящих маленьких LAS в QThread, автоматический выбор, объединение и сохранение классов, удаление без удаления исходников, повторное добавление, совпадение географического положения разных UTM-зон, ограниченное чтение большого LAS, MBTiles/TMS, порядок осей WMS 1.3.0, журнал ошибок и компоновка. Проверены резервное копирование, повторная установка и точный откат.

При подготовке глобус проверен в Chromium с программным WebGL и заблокированными внешними запросами. Для исходного GPU/драйвера пользователя гарантий этот тест не даёт. Основной GUI тестируется с заменой OpenGL/Open3D контейнера; PostgreSQL и полная цепочка обучения не запускались. Google/Bing/Яндекс проверены на модельных ответах API без ключей и тарифицируемых запросов.

При ошибках приложите `city3d_globe_verification.json` и `WORKSPACE/city3d_load_errors.log`, а также текст ошибки в браузере. Если файл исчез/перемещён, добавьте актуальный путь заново.
